# Rover

A terminal exploration game. `ROVER_DATA_DIR` selects its data directory; development runs use `dev-data/`, which `.gitignore` excludes.

- Player profiles: `<data dir>/profiles.json`, read and written by `src/profiles.ts`.
- Save slots: `<data dir>/saves/<slot>.json`, read and written by `src/saves.ts`.

Version 0.1.0 is published on the project's releases page and installed by its players.
