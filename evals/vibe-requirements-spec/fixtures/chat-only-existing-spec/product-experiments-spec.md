## User goal
Explore a small feature-flag experiment workflow.

## Current requirements

### Confirmed requirements
- Product managers can define one experiment variant.

### Proposed defaults
- Keep rollout internal-only until approval.

### Ideas or options
- Variant preview, audit notes, or dashboard summary.

### Decisions needed
- Decide whether dashboard summary is in the first slice.

### Assumptions
- Existing feature flags can represent one variant.

### Out of scope
- Automatic statistical analysis.

## Acceptance criteria
- Product managers can review the current experiment setup before later planning.

## Open risks and unknowns
- Experiment dashboard scope is unresolved.
